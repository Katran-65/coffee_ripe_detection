Научный руководитель: Доронькин Максим Вячеславович

### ЦЕЛЬ ЭКСПЕРИМЕНТА:
Создать систему компьютерного зрения для автоматической детекции и классификации кофейных зерен по пяти категориям зрелости. Это критически важная задача для кофейной индустрии, поскольку качество конечного продукта напрямую зависит от своевременного сбора зерен нужной спелости.

### КАТЕГОРИИ ЗРЕЛОСТИ:
dry (высушенные)
ripe (спелые)
overripe (перезрелые)
semi_ripe (полуспелые)
unripe (незрелые)

### ДАННЫЕ:
Формат: аннотации COCO (bounding boxes с категориями)
Разбиение: train (2061 изображения), valid (201), test (98)
Всего аннотаций: 34124 объектов
Данные содержатся в папке datas

### НОУТБУКИ:
В ноутбуке coffee_detection.ipynb представлено комплексное исследование, в рамках которого были реализованы и протестированы три современные архитектуры детекции объектов: YOLOv8n, YOLOv26n и Faster R-CNN, а также проведен экспериментальный анализ трансформерной модели DETR. По результатам экспериментов наилучшую производительность показала модель YOLOv26n, достигнув значения mAP@50 = 66.5% при минимальном размере весов (5.4 MB) и высокой скорости инференса, что делает её оптимальным выбором для практического применения в реальных условиях кофейного производства.

В ноутбуке coffee_detection_moz.ipynb представлен полный пайплайн обработки данных и обучения моделей. Для повышения качества и устойчивости модели были применены расширенные техники аугментации: создание мозаичных изображений из нескольких исходных, а также генерация копий с пониженным разрешением для имитации различных условий съемки.
